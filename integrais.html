Integrais

A integral é a operação que acumula: soma infinitesimal de fatias para calcular áreas, volumes, trabalho, probabilidade e muito mais. Geometricamente, a integral definida é a área limitada pela curva e pelo eixo x.

Conceito

A integral definida de f de a até b é a soma das áreas das fatias verticais sob a curva, com espessura tendendo a zero:

∫ab f(x) dx = limn→∞ Σ f(xᵢ)·Δx
  • ∫ = soma (do latim sum); dx = espessura infinitesimal da fatia.
  • Limites de integração: a (inferior) e b (superior).
  • Sinal: se a função fica abaixo do eixo x, a área conta como negativa.
  • Integral indefinida = conjunto das antiderivadas: ∫ f(x) dx = F(x) + C, com F′ = f.
Teorema Fundamental do Cálculo: derivar e integrar são operações inversas. Se F′ = f, então ∫ab f(x) dx = F(b) − F(a). É isso que permite calcular áreas sem somar infinitas fatias.

Área vs. integral

  • Área sempre é positiva: use módulo quando a curva desce abaixo do eixo.
  • Integral acumula sinal: parte negativa “cancela” parte positiva.

Tipos de integrais

Tipo 1

Integral indefinida

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C

Resultado é uma função + constante C (família de antiderivadas).

Tipo 2

Integral definida

∫ab f(x) dx = F(b) − F(a)

Resultado é um número — representa a área com sinal.

Método

Por substituição

∫ f(g(x))·g′(x) dx → ∫ f(u) du

Escolha u = g(x) para simplificar a expressão.

Método

Por partes

∫ u dv = u·v − ∫ v du

Útil em produtos como x·eˣ ou x·sen x.

Aplicação

Área entre curvas

∫ab [f(x) − g(x)] dx

Área entre duas funções, integrando a de cima menos a de baixo.

Aplicação

Funções definidas

P(X ≤ x) = ∫ f(t) dt

Probabilidade, trabalho, deslocamento a partir da velocidade…

Exemplos resolvidos

Exemplo 1 — Integral indefinida

∫ (3x² + 2x − 5) dx

  1. Integre termo a termo pela potência: ∫3x² dx = x³.
  2. ∫2x dx = x² e ∫5 dx = 5x.
  3. Resultado: x³ + x² − 5x + C.
  4. Confira derivando: a derivada devolve a expressão original.

Exemplo 2 — Integral definida pelo Teorema Fundamental

∫02 x² dx

  1. Antiderivada: F(x) = x³/3.
  2. Avalie no limite superior: F(2) = 8/3.
  3. Avalie no inferior: F(0) = 0.
  4. Resultado: 8/3 − 0 = 8/3 ≈ 2,6667 (área sob y = x² de 0 a 2).

Exemplo 3 — Funções notáveis

  1. ∫ 1/x dx = ln|x| + C (para x ≠ 0).
  2. ∫ eˣ dx = eˣ + C.
  3. ∫ sen x dx = −cos x + C; ∫ cos x dx = sen x + C.
  4. ∫ aˣ dx = aˣ/ln a + C.

Exemplo 4 — Área com sinal

∫02π sen x dx

  1. Antiderivada: −cos x.
  2. Avalie: (−cos 2π) − (−cos 0) = (−1) − (−1) = 0.
  3. Resultado zero porque as áreas acima e abaixo do eixo se cancelam.
  4. A área geométrica seria 2 + 2 = 4 (soma dos módulos).

Gráficos interativos — área sob a curva

Digite a função e os limites de integração. A área sombreada é a integral definida — o valor numérico é calculado por integração de Simpson.

Repare: em ∫−22 (x³ − 3x) dx a integral dá zero — a função é ímpar e as áreas se cancelam. Já a área total somaria os módulos das duas “bolsas”.

Exercícios resolvidos

Resolvido A — ∫13 (2x + 1) dx

  1. Antiderivada: F(x) = x² + x.
  2. F(3) = 9 + 3 = 12.
  3. F(1) = 1 + 1 = 2.
  4. Resultado: 12 − 2 = 10.

Resolvido B — ∫ x·√x dx (simplifique antes)

  1. x·√x = x·x^(1/2) = x^(3/2).
  2. Some 1 ao expoente: 3/2 + 1 = 5/2.
  3. Resultado: x^(5/2)/(5/2) + C = (2/5)·x^(5/2) + C.

Resolvido C — Área de um triângulo pela integral

∫04 (−x + 4) dx

  1. A reta forma um triângulo de base 4 e altura 4 → área 8.
  2. Pela integral: antiderivada −x²/2 + 4x.
  3. Avalie em 4: −8 + 16 = 8; em 0: 0.
  4. Resultado: 8 — bateu com a geometria!

Questão 2 — Integral de uma função linear

Solução passo a passo

  1. Antiderivada: F(x) = m·x²/2 + b·x.
  2. F(s) − F(i) = m/2·(s² − i²) + b·(s − i).
  3. Substitua os valores e calcule.

Questão 3 — De zero até b

Calcule ∫0b k·xⁿ dx com k = , n = , b = .

Solução passo a passo

  1. F(x) = k·xⁿ⁺¹/(n+1).
  2. F(b) = k·bⁿ⁺¹/(n+1) e F(0) = 0 (para n > −1).
  3. Subtraia: sobra k·bⁿ⁺¹/(n+1).

  2. F(s) − F(i) = a/3·(s³ − i³) + b/2·(s² − i²) + c·(s − i).

Solução passo a passo
