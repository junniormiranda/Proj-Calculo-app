Funções

A função é a base de todo o Cálculo: uma relação que associa cada elemento de um conjunto (entrada) a exatamente um elemento de outro conjunto (saída). Aqui você verá conceito, tipos, gráficos interativos e exercícios com correção automática.

Conceito

Uma função f é uma regra que associa a cada valor x de um conjunto D exatamente um valor y = f(x).

f : D → C     x ↦ f(x)
  • Domínio (D): conjunto de todos os valores de entrada possíveis de x.
  • Imagem (C): conjunto de todos os valores de saída f(x).
  • Variação: outro nome usado para a imagem em alguns livros.
  • Gráfico: conjunto de pontos (x, f(x)) no plano cartesiano.
Como saber se é uma função? Pelo teste vertical: qualquer linha vertical que intersecta o gráfico pode cruzá-lo no máximo uma vez. Se cruza duas vezes, não é função.

Formas de representação

  • Analítica (fórmula): f(x) = 3x − 2
  • Numérica (tabela): pares (x, f(x)).
  • Gráfica: a curva desenhada no plano.
  • Verbal: uma regra escrita com palavras.

Tipos de funções

Arraste os controles ao lado de cada tipo para ver como os coeficientes mudam o gráfico.

Tipo 1

Função constante

f(x) = b

A saída é sempre a mesma, qualquer que seja x. Gráfico: reta horizontal na altura b.

Mova b: a reta sobe ou desce, mas nunca inclina.

Tipo 2

Função afim

f(x) = ax + b  (a ≠ 0)

Gráfico: reta. a = coeficiente angular (inclinação); b = coeficiente linear (corte no eixo y). Raiz em x = −b/a.

Mova a para mudar a inclinação e b para deslocar a reta. Os pontos marcam o corte no eixo y e a raiz.

Tipo 3

Função linear

f(x) = ax  (a ≠ 0)

Caso particular da afim com b = 0. Gráfico: reta que passa pela origem; y é proporcional a x.

Mova a: a reta gira em torno da origem. Com a < 0 ela passa a descer.

Tipo 4

Função exponencial

f(x) = aˣ  (a > 0, a ≠ 1)

Cresce (a > 1) ou decresce (0 < a < 1). Sempre positiva; passa por (0, 1).

Mova a entre 0 e 1 e depois acima de 1: a curva troca de crescente para decrescente, mas sempre passa por (0, 1).

Tipo 5

Função logarítmica

f(x) = loga(x)  (a > 0, a ≠ 1)

Inversa da exponencial. Domínio: x > 0; passa por (1, 0); assíntota vertical em x = 0.

Mova a: todas as curvas passam por (1, 0), e o ponto (a, 1) acompanha a base.

Monte o seu próprio gráfico

Sintaxe: use ^ para potência (x^2), * para multiplicação (3*x) e as funções sin, cos, tan, ln, log, sqrt, abs, exp. Também aceitamos 2x (sem o asterisco).

Exercícios resolvidos

Um exercício para cada tipo de função, resolvido passo a passo.

Resolvido A — Função constante: mensalidade fixa

Uma academia cobra R$ 90 por mês, não importa quantas vezes o aluno frequente. Escreva a função do valor pago em função do número x de visitas no mês, calcule f(4) e f(20) e dê a imagem.

  1. O valor não depende de x, então a função é constante: f(x) = 90.
  2. Para qualquer entrada a saída é a mesma: f(4) = 90 e f(20) = 90.
  3. O gráfico é uma reta horizontal na altura 90.
  4. Imagem: um único valor, Im = {90}.

Resolvido B — Função afim: corrida de táxi

Um táxi cobra bandeirada de R$ 5,00 mais R$ 2,50 por quilômetro rodado. Quanto custa uma corrida de 12 km? E quantos quilômetros é possível rodar com R$ 50,00?

  1. Parte fixa (b) mais parte proporcional (a·x): f(x) = 2,5x + 5.
  2. Corrida de 12 km: f(12) = 2,5·12 + 5 = 30 + 5 = 35 → R$ 35,00.
  3. Com R$ 50: 2,5x + 5 = 50 ⇒ 2,5x = 45 ⇒ x = 18.
  4. Resultado: 12 km custam R$ 35,00, e R$ 50,00 pagam 18 km.

Resolvido C — Função linear: encontrar a lei pelo gráfico

O gráfico de uma função linear passa pelo ponto (4, 10). Determine a lei da função e calcule f(6).

  1. Função linear tem a forma f(x) = ax (passa pela origem).
  2. Use o ponto dado: f(4) = 10 ⇒ 4a = 10 ⇒ a = 2,5.
  3. Lei da função: f(x) = 2,5x.
  4. Resultado: f(6) = 2,5·6 = 15. Note que dobrar x dobra y: é proporcionalidade direta.

Resolvido D — Função exponencial: crescimento de bactérias

Uma cultura começa com 500 bactérias e a população dobra a cada hora, ou seja, N(t) = 500·2ᵗ (t em horas). Quantas bactérias haverá após 5 horas? Em quanto tempo a população chega a 8 000?

  1. Após 5 horas: N(5) = 500·2⁵ = 500·32 = 16 000 bactérias.
  2. Para 8 000: 500·2ᵗ = 8 000 ⇒ 2ᵗ = 16.
  3. Escreva 16 como potência de 2: 2ᵗ = 2⁴ ⇒ t = 4.
  4. Resultado: 16 000 bactérias em 5 h; a população chega a 8 000 em 4 horas.

Resolvido E — Função logarítmica: valores e equação

Dada f(x) = log3(x), calcule f(81) e f(1/9), encontre x tal que f(x) = 2 e dê o domínio.

  1. Definição: log3(x) = y ⇔ 3ʸ = x.
  2. f(81): 3ʸ = 81 = 3⁴ ⇒ f(81) = 4.
  3. f(1/9): 3ʸ = 1/9 = 3⁻² ⇒ f(1/9) = −2.
  4. f(x) = 2 ⇒ x = 3² = 9.
  5. Domínio: o logaritmo só existe para x > 0, então D = (0, +∞).

Questão 1 — Avaliação de função

Sendo f(x) = a·x + b com a = , b = e x₀ = , determine f(x₀).

Solução passo a passo

  1. Escreva a função com os valores: f(x) = a·x + b.
  2. Substitua x por x₀: f(x₀) = a·x₀ + b.
  3. Multiplique a por x₀ e some b.
  4. Fórmula usada: f(x₀) = a·x₀ + b.

Questão 2 — Raiz de uma função linear

Para f(x) = a·x + b com a = e b = , encontre o valor de x em que f(x) = 0.

Solução passo a passo

  1. Iguale a função a zero: a·x + b = 0.
  2. Isole o termo com x: a·x = −b.
  3. Divida por a: x = −b / a.

Questão 3 — Domínio da função racional

Sendo f(x) = 1 / (x − k) com k = , qual valor de x não pertence ao domínio?

Solução passo a passo

  1. O denominador não pode ser zero: x − k ≠ 0.
  2. Portanto x ≠ k.
  3. Domínio: D = ℝ − {k}.

Questão 4 — Função exponencial

Para f(x) = k·bˣ com k = , b = e x₀ = , calcule f(x₀).

Solução passo a passo

  1. Substitua: f(x₀) = k · bx₀.
  2. Calcule a potência bx₀ e multiplique por k.
  3. Use a calculadora para potências com expoente decimal.
