Funções

A função é a base de todo o Cálculo: uma relação que associa cada elemento de um conjunto (entrada) a exatamente um elemento de outro conjunto (saída). Aqui você verá conceito, tipos, exemplos, gráficos interativos e exercícios com correção automática.

Conceito

Uma função f é uma regra que associa a cada valor x de um conjunto D exatamente um valor y = f(x).

f : D → C     x ↦ f(x)
  • Domínio (D): conjunto de todos os valores de entrada possíveis de x.
  • Imagem (C): conjunto de todos os valores de saída f(x).
  • Variação: outro nome usado para a imagem em alguns livros.
  • Gráfico: conjunto de pontos (x, f(x)) no plano cartesiano.
Como saber se é uma função? Pelo teste vertical: qualquer linha vertical que intersecta o gráfico pode cruzá-lo no máximo uma vez. Se cruza duas vezes, não é função.

Formas de representação

  • Analítica (fórmula): f(x) = 3x − 2
  • Numérica (tabela): pares (x, f(x)).
  • Gráfica: a curva desenhada no plano.
  • Verbal: uma regra escrita com palavras.

Tipos de funções

Grau 1

Linear

f(x) = ax + b  (a ≠ 0)

Gráfico: reta. Coeficiente a = inclinação; b = altura em x = 0.

Grau 2

Quadrática

f(x) = ax² + bx + c

Gráfico: parábola. Vértice em x = −b/2a; se a > 0 abre para cima.

Grau n

Polinomial

f(x) = aₙxⁿ + … + a₁x + a₀

Soma de potências de x. Raízes: valores em que f(x) = 0.

Razão

Racional

f(x) = p(x) / q(x)

Onde q(x) = 0 a função não existe (buraco na reta vertical).

Crescimento

Exponencial

f(x) = a·bˣ  (b > 0, b ≠ 1)

Cresce (b > 1) ou decai (0 < b < 1) rapidamente. Nunca zera.

Inversa da exponencial

Logarítmica

f(x) = logb(x)

Domínio: x > 0. Crescente se b > 1; assíntota vertical em x = 0.

Periódica

Trigonométrica

f(x) = sen(x), cos(x), tan(x)

Oscilam em ciclos (período 2π para seno e cosseno).

Não diferenciável no “canto”

Valor absoluto

f(x) = |x|

Gráfico em “V”. Vértice em x = 0; usada em problemas de distância.

Exemplos resolvidos

Exemplo 1 — Domínio de uma função racional

f(x) = 1 / (x − 5)

  1. A única restrição é o denominador diferente de zero: x − 5 ≠ 0.
  2. Portanto x ≠ 5.
  3. Domínio: todos os reais menos 5, isto é D = ℝ − {5}.

Exemplo 2 — Vértice de uma parábola

f(x) = x² − 6x + 5

  1. Coeficientes: a = 1, b = −6, c = 5.
  2. Abscissa do vértice: xv = −b / 2a = 6 / 2 = 3.
  3. Ordenada: f(3) = 9 − 18 + 5 = −4.
  4. Vértice: (3, −4) — é o ponto de mínimo, pois a > 0.

Exemplo 3 — Raízes de uma função

f(x) = x² − 4

  1. Buscar x tal que f(x) = 0: x² − 4 = 0.
  2. Fatorar: (x − 2)(x + 2) = 0.
  3. Raízes: x = 2 e x = −2 — são os cortes no eixo x.

Exercícios resolvidos

Resolvido A — Calcule f(3) para f(x) = 4x − 7

  1. Substitua x = 3 na fórmula: f(3) = 4·3 − 7.
  2. Multiplique: f(3) = 12 − 7.
  3. Resultado: f(3) = 5.

Resolvido B — Domínio de f(x) = √(x − 2)

  1. A raiz exige o radicando não negativo: x − 2 ≥ 0.
  2. Resolvendo: x ≥ 2.
  3. Domínio: D = [2, +∞).

Resolvido C — Imagem de f(x) = x² para x ∈ ℝ

  1. Qualquer número real ao quadrado é maior ou igual a zero.
  2. O menor valor atingido é 0 (em x = 0).
  3. Imagem: C = [0, +∞).

Questão 1 — Avaliação de função

Sendo f(x) = a·x + b com a = , b = e x₀ = , determine f(x₀).

Solução passo a passo

  1. Escreva a função com os valores: f(x) = a·x + b.
  2. Substitua x por x₀: f(x₀) = a·x₀ + b.
  3. Multiplique a por x₀ e some b.
  4. Fórmula usada: f(x₀) = a·x₀ + b.

Questão 2 — Raiz de uma função linear

Para f(x) = a·x + b com a = e b = , encontre o valor de x em que f(x) = 0.

Solução passo a passo

  1. Iguale a função a zero: a·x + b = 0.
  2. Isole o termo com x: a·x = −b.
  3. Divida por a: x = −b / a.

Questão 3 — Vértice da parábola

Dada f(x) = a·x² + b·x + c com a = , b = e c = , determine as coordenadas do vértice (xv, yv).

Solução passo a passo

  1. Abcissa do vértice: xv = −b / (2a).
  2. Ordem: substitua xv em f. Uma forma rápida: yv = c − b² / (4a).
  3. O vértice é o ponto de máximo (se a < 0) ou mínimo (se a > 0).

Questão 4 — Domínio da função racional

Sendo f(x) = 1 / (x − k) com k = , qual valor de x não pertence ao domínio?

Solução passo a passo

  1. O denominador não pode ser zero: x − k ≠ 0.
  2. Portanto x ≠ k.
  3. Domínio: D = ℝ − {k}.

Questão 5 — Função exponencial

Para f(x) = k·bˣ com k = , b = e x₀ = , calcule f(x₀).

Solução passo a passo

  1. Substitua: f(x₀) = k · bx₀.
  2. Calcule a potência bx₀ e multiplique por k.
  3. Use a calculadora para potências com expoente decimal.
