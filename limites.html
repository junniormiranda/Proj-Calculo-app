Limites

O limite responde à pergunta: para onde a função tende quando x se aproxima de um certo valor? É o olhar de perto — o valor da função próximo ao ponto, e não necessariamente no ponto. É a porta de entrada para derivadas e integrais.

Conceito

Dizemos que o limite de f(x) quando x tende a a é L quando, ao nos aproximarmos cada vez mais de a (por qualquer caminho), os valores de f(x) se aproximam cada vez mais de L:

limx→a f(x) = L
  • Não importa o valor em x = a: a função pode nem estar definida ali. O limite fala do entorno.
  • Limite lateral à direita: limx→a⁺ f(x) — caminho com x > a.
  • Limite lateral à esquerda: limx→a⁻ f(x) — caminho com x < a.
  • Limite existe quando os dois laterais existem e são iguais.
Definição formal (ε–δ): limx→a f(x) = L significa que para todo ε > 0 existe um δ > 0 tal que, sempre que 0 < |x − a| < δ, temos |f(x) − L| < ε. Ou seja: eu posso tornar f(x) tão perto de L quanto quiser, bastando escolher x suficientemente próximo de a.

Tipos / casos de limites

Caso 1

Por substituição direta

Funções contínuas: substitua x por a. Ex.: lim x→3 (x² + 1) = 10.

Caso 2

Indeterminação 0/0

Fatorar, racionalizar ou simplificar antes de substituir. Ex.: lim x→2 (x²−4)/(x−2) = 4.

Caso 3

Limites laterais

Pedaços da função ou |x|/x: calcule os dois lados. Se diferem → limite não existe.

Caso 4

x → ∞ (assíntota horizontal)

Compare graus do numerador e denominador. Ex.: lim x→∞ (3x²+1)/(5x²−2) = 3/5.

Caso 5

Infinito (assíntota vertical)

lim x→a f(x) = ∞ não é número: a função “dispara”. Ex.: lim x→0 1/x² = ∞.

Caso 6

Trigonométricos notáveis

limx→0 sen(x)/x = 1

E limx→0 (1 − cos x)/x = 0.

Exemplos resolvidos

Exemplo 1 — Indeterminação 0/0

limx→3 (x² − 9)/(x − 3)

  1. Substituindo: (9 − 9)/(3 − 3) = 0/0 → indeterminado.
  2. Fatore o numerador: (x − 3)(x + 3)/(x − 3).
  3. Para x ≠ 3 o fator comum simplifica: sobra x + 3.
  4. Agora substitua: 3 + 3 = 6.
  5. Resposta: 6.

Exemplo 2 — Limite trigonométrico

limx→0 sen(5x)/x

  1. Multiplique e divida por 5: 5 · sen(5x)/(5x).
  2. Seja u = 5x; quando x→0, u→0.
  3. Usando limu→0 sen(u)/u = 1: 5 · 1 = 5.
  4. Resposta: 5.

Exemplo 3 — x tende ao infinito

limx→∞ (4x² + 3x)/(2x² − 1)

  1. Numerador e denominador têm o mesmo grau (2).
  2. Divida tudo por x²: (4 + 3/x)/(2 − 1/x²).
  3. Quando x→∞ os termos 3/x e 1/x² tendem a 0.
  4. Sobra 4/2 = 2.
  5. Resposta: 2.

Exercícios resolvidos

Resolvido A — limx→3 (x² − 5x + 6)/(x − 3)

  1. Substituição dá 0/0: precisa simplificar.
  2. Fatore: x² − 5x + 6 = (x − 2)(x − 3).
  3. Simplifique o (x − 3): sobra x − 2.
  4. Substitua x = 3: 3 − 2 = 1.
  5. Resposta: 1.

Resolvido B — limx→0 (sen(2x))/(3x)

  1. Escreva (2/3) · [sen(2x)/(2x)].
  2. Como limu→0 sen(u)/u = 1, o colchete tende a 1.
  3. Resposta: 2/3 ≈ 0,6667.

Resolvido C — limx→1⁻ e limx→1⁺ de f(x)

f(x) = x + 1, se x < 1  |  f(x) = 3x, se x ≥ 1

  1. Lado esquerdo: limx→1⁻ (x + 1) = 2.
  2. Lado direito: limx→1⁺ 3x = 3.
  3. Como 2 ≠ 3, os laterais diferem.
  4. O limite não existe.

Questão 1 — Indeterminação clássica

Calcule limx→a (x² − a²)/(x − a), sabendo que a = .

Solução passo a passo

  1. Fatore a diferença de quadrados: (x − a)(x + a).
  2. Simplifique com o denominador: sobra x + a.
  3. Substitua x = a: a + a = 2a.

Questão 2 — Limite trigonométrico

Calcule limx→0 sen(k·x)/x para k = .

Solução passo a passo

  1. Multiplique e divida por k: k · sen(kx)/(kx).
  2. Como x→0, também kx→0.
  3. Como limu→0 sen(u)/u = 1, o resultado é k · 1 = k.

Questão 3 — Limite no infinito

Calcule limx→∞ (m·x² + 3)/(n·x² − 5) com m = e n = .

Solução passo a passo

  1. Os dois polinomios têm o mesmo grau (2).
  2. Divida tudo por x²: (m + 3/x²)/(n − 5/x²).
  3. Com x→∞, os termos com x no denominador vão a zero.
  4. Sobra m/n.

Questão 4 — Diferência de cubos

Calcule limx→a (x³ − a³)/(x − a) para a = .

Solução passo a passo

  1. Identidade: x³ − a³ = (x − a)(x² + x·a + a²).
  2. Simplifique o fator (x − a).
  3. Substitua x = a: a² + a² + a² = 3a².

Questão 5 — Limite com duas constantes

Calcule limx→0 sen(k·x)/(m·x) com k = e m = (m ≠ 0).

Solução passo a passo

  1. Reescreva: (k/m) · [sen(kx)/(kx)].
  2. O colchete tende a 1 quando x→0.
  3. Resultado: k/m.
