Derivadas

A derivada mede a taxa de variação instantânea de uma função. Geometricamente, é a inclinação da reta tangente ao gráfico em um ponto. É a ferramenta que transforma “quanto muda?” em “quanto muda neste instante exato?”.

Conceito

A derivada de f em x é o limite da taxa de variação média quando o incremento h tende a zero:

f′(x) = limh→0 [ f(x + h) − f(x) ] / h
  • Taxa média (secante): [f(b) − f(a)] / (b − a).
  • Taxa instantânea (tangente): o que acontece quando o intervalo encolhe até zero.
  • Notações: f′(x), y′, df/dx.
  • Se o limite não existe, a função não é diferenciável naquele ponto (ex.: o “canto” de |x| em 0).
Interpretações: velocidade instantânea (física), taxa de crescimento (biologia/economia), inclinação da reta tangente (geometria) e marginal em otimização (aplicação clássica).

O que a derivada diz sobre o gráfico

  • f′(x) > 0 → função crescente naquele trecho.
  • f′(x) < 0 → função decrescente.
  • f′(x) = 0 → ponto crítico (candidato a máximo ou mínimo).
  • f″(x) > 0 → côncava para cima; f″(x) < 0 → para baixo.

Regras de derivação

Básica

Constante e potência

(c)′ = 0    (xⁿ)′ = n·xⁿ⁻¹

Ex.: (x⁵)′ = 5x⁴  ·  (7)′ = 0.

Constante

Múltiplo e soma

(c·f)′ = c·f′  ·  (f ± g)′ = f′ ± g′

Derivar é linear: deriva termo a termo.

Produto

Regra do produto

(f·g)′ = f′·g + f·g′

“primeiro derivado vezes segundo + primeiro vezes segundo derivado”.

Quociente

Regra do quociente

(f/g)′ = (f′·g − f·g′) / g²

Atenção ao sinal: o derivado do numerador vem primeiro.

Composição

Regra da cadeia

[f(g(x))]′ = f′(g(x))·g′(x)

Derive a “casca” e multiplique pela derivada do “miolo”.

Elementares

Derivadas conhecidas

(eˣ)′ = eˣ  ·  (ln x)′ = 1/x
(sen x)′ = cos x  ·  (cos x)′ = −sen x

(aˣ)′ = aˣ·ln a  ·  (√x)′ = 1/(2√x).

Exemplos resolvidos

Exemplo 1 — Polinômio (termo a termo)

f(x) = 3x⁴ − 5x² + 7

  1. Derive a primeira parcela: (3x⁴)′ = 3·4·x³ = 12x³.
  2. Derive a segunda: (−5x²)′ = −5·2·x = −10x.
  3. A constante some: (7)′ = 0.
  4. Resultado: f′(x) = 12x³ − 10x.

Exemplo 2 — Regra do produto

f(x) = x² · sen(x)

  1. Chame u = x² e v = sen(x).
  2. u′ = 2x e v′ = cos(x).
  3. f′ = u′v + uv′ = 2x·sen(x) + x²·cos(x).
  4. Resultado: f′(x) = 2x·sen(x) + x²·cos(x).

Exemplo 3 — Regra do quociente

f(x) = (x + 1)/(x − 1)

  1. Numerador u = x + 1 → u′ = 1; denominador v = x − 1 → v′ = 1.
  2. f′ = [1·(x − 1) − (x + 1)·1] / (x − 1)².
  3. Simplifique o numerador: x − 1 − x − 1 = −2.
  4. Resultado: f′(x) = −2/(x − 1)².

Exemplo 4 — Regra da cadeia

f(x) = (3x² + 1)⁵

  1. Casca: potência 5 → 5(3x² + 1)⁴.
  2. Miolo: (3x² + 1)′ = 6x.
  3. Multiplique: f′ = 5(3x² + 1)⁴ · 6x.
  4. Resultado: f′(x) = 30x·(3x² + 1)⁴.

Gráficos interativos — tangente e secante

Escolha uma função e um ponto. A linha tracejada azul é a secante (taxa média) e a rosa é a tangente (derivada). Quanto menor o passo h, mais a secante “vira” tangente — é o limite acontecendo!

O que observar: em f(x) = x² com x₀ = 1, a derivada é f′(1) = 2. Reduzindo h, a inclinação da secante se aproxima de 2 — visualização direta da definição.

Exercícios resolvidos

Resolvido A — Derivada em um ponto

f(x) = 5x³ − 2x + 4, calcule f′(2)

  1. Derive: f′(x) = 15x² − 2.
  2. Substitua x = 2: 15·4 − 2 = 58.
  3. Resposta: f′(2) = 58.

Resolvido B — Reta tangente

Ache a equação da tangente de f(x) = x² em x₀ = 3

  1. Derivada: f′(x) = 2x → inclinação m = f′(3) = 6.
  2. Ponto: f(3) = 9, ou seja (3, 9).
  3. Usando y − y₀ = m(x − x₀): y − 9 = 6(x − 3).
  4. Resposta: y = 6x − 9.

Resolvido C — Ponto crítico

f(x) = x² − 6x + 11

  1. f′(x) = 2x − 6.
  2. Iguale a zero: 2x − 6 = 0 → x = 3.
  3. f(3) = 9 − 18 + 11 = 2 → ponto (3, 2).
  4. Como f″ = 2 > 0, é um mínimo.

Questão 1 — Derivada de uma potência

Seja f(x) = a·xⁿ com a = , n = e x₀ = . Calcule f′(x₀).

Solução passo a passo

  1. Pela regra da potência: f′(x) = a·n·xⁿ⁻¹.
  2. Substitua x = x₀: f′(x₀) = a·n·x₀ⁿ⁻¹.
  3. Cuidado: o expoente da derivada é n − 1.

Questão 2 — Regra do produto

Sendo f(x) = (a·x + b)·(c·x + d), calcule f′(x₀) para a = , b = , c = , d = , x₀ = .

Solução passo a passo

  1. Chame u = a·x + b (logo u′ = a) e v = c·x + d (v′ = c).
  2. f′(x) = a·(c·x + d) + c·(a·x + b).
  3. Substitua x = x₀ na fórmula acima.

Questão 3 — Regra do quociente

Para f(x) = (a·x + b)/(c·x + d), calcule f′(x₀) com a = , b = , c = , d = , x₀ = .

Solução passo a passo

  1. u = a·x + b → u′ = a; v = c·x + d → v′ = c.
  2. f′ = (u′v − uv′)/v².
  3. f′(x) = [a·(c·x + d) − c·(a·x + b)] / (c·x + d)².
  4. Substitua x = x₀.

Questão 4 — Regra da cadeia

Sendo f(x) = (a·x + b)ⁿ, calcule f′(x₀) para a = , b = , n = , x₀ = .

Solução passo a passo

  1. Casca (potência): n·(a·x + b)ⁿ⁻¹.
  2. Miolo (derivada interna): a.
  3. f′(x) = a·n·(a·x + b)ⁿ⁻¹; substitua x = x₀.
