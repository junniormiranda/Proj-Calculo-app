Derivadas

A derivada mede a taxa de variação instantânea de uma função. Geometricamente, é a inclinação da reta tangente ao gráfico em um ponto. É a ferramenta que transforma “quanto muda?” em “quanto muda neste instante exato?”.

Conceito

A derivada de f em x é o limite da taxa de variação média quando o incremento h tende a zero:

f′(x) = limh→0 [ f(x + h) − f(x) ] / h
  • Taxa média (secante): [f(b) − f(a)] / (b − a).
  • Taxa instantânea (tangente): o que acontece quando o intervalo encolhe até zero.
  • Notações: f′(x), y′, df/dx.
  • Se o limite não existe, a função não é diferenciável naquele ponto (ex.: o “canto” de |x| em 0).
Interpretações: velocidade instantânea (física), taxa de crescimento (biologia/economia), inclinação da reta tangente (geometria) e marginal em otimização (aplicação clássica).

O que a derivada diz sobre o gráfico

  • f′(x) > 0 → função crescente naquele trecho.
  • f′(x) < 0 → função decrescente.
  • f′(x) = 0 → ponto crítico (candidato a máximo ou mínimo).
  • f″(x) > 0 → côncava para cima; f″(x) < 0 → para baixo.

Regras de derivação

Arraste os controles ao lado de cada item para ver o gráfico responder.

Básica

Constante e potência

(c)′ = 0    (xⁿ)′ = n·xⁿ⁻¹

Ex.: (x⁵)′ = 5x⁴  ·  (7)′ = 0.

Mova n e x₀. Laranja: f(x). Azul tracejado: f′(x). Rosa: a reta tangente, cuja inclinação é a altura do ponto azul.

Linearidade

Múltiplo e soma

(c·f)′ = c·f′  ·  (f ± g)′ = f′ ± g′

Derivar é linear: derive termo a termo e mantenha as constantes multiplicando.

Mova c e d em f(x) = c·x³ + d·x: onde f′ cruza o zero, a tangente fica horizontal.

Produto

Regra do produto

(f·g)′ = f′·g + f·g′

“Primeiro derivado vezes o segundo + primeiro vezes o segundo derivado.” Ex.: (x·sen x)′ = sen x + x·cos x.

Mova x₀ ao longo de f(x) = x·sen(x) e acompanhe a inclinação da tangente.

Quociente

Regra do quociente

(f/g)′ = (f′·g − f·g′) / g²

Atenção ao sinal: a derivada do numerador vem primeiro. Ex.: [(x + 1)/(x − 1)]′ = −2/(x − 1)².

Mova x₀: f′ é sempre negativa, então a função decresce dos dois lados de x = 1.

Composição

Regra da cadeia

[f(g(x))]′ = f′(g(x))·g′(x)

Derive a “casca” e multiplique pela derivada do “miolo”. Ex.: [sen(kx)]′ = k·cos(kx).

Mova k: a curva fica mais apertada e a derivada é multiplicada por k.

Elementares

Derivadas conhecidas

(eˣ)′ = eˣ  ·  (ln x)′ = 1/x
(sen x)′ = cos x  ·  (cos x)′ = −sen x

(aˣ)′ = aˣ·ln a  ·  (√x)′ = 1/(2√x).

Troque a função e mova x₀. Repare que, para eˣ, as curvas de f e f′ coincidem.

Explore a tangente e a secante

Escolha uma função e um ponto. A linha tracejada azul é a secante (taxa média) e a rosa é a tangente (derivada). Quanto menor o passo h, mais a secante “vira” tangente — é o limite acontecendo!

O que observar: em f(x) = x² com x₀ = 1, a derivada é f′(1) = 2. Reduzindo h, a inclinação da secante se aproxima de 2 — visualização direta da definição.

Exercícios resolvidos

Um exercício para cada regra de derivação, resolvido passo a passo.

Resolvido A — Constante e potência

Para f(x) = x⁴ e g(x) = 7, calcule f′(2) e g′(x).

  1. Regra da potência: f′(x) = 4x³.
  2. Em x = 2: f′(2) = 4·8 = 32.
  3. Constante tem derivada zero: g′(x) = 0.
  4. Resposta: f′(2) = 32 e g′(x) = 0.

Resolvido B — Múltiplo e soma

Para f(x) = 5x³ − 2x + 4, calcule f′(2).

  1. Derive termo a termo: (5x³)′ = 15x², (−2x)′ = −2, (4)′ = 0.
  2. f′(x) = 15x² − 2.
  3. Substitua x = 2: 15·4 − 2 = 58.
  4. Resposta: f′(2) = 58.

Resolvido C — Regra do produto

Derive f(x) = x·eˣ e calcule f′(0).

  1. Chame u = x e v = eˣ: u′ = 1 e v′ = eˣ.
  2. f′ = u′v + uv′ = eˣ + x·eˣ = (1 + x)·eˣ.
  3. Em x = 0: (1 + 0)·e⁰ = 1.
  4. Resposta: f′(x) = (1 + x)eˣ e f′(0) = 1.

Resolvido D — Regra do quociente

Derive f(x) = (x + 1)/(x − 1) e calcule f′(3).

  1. Numerador u = x + 1 → u′ = 1; denominador v = x − 1 → v′ = 1.
  2. f′ = [1·(x − 1) − (x + 1)·1] / (x − 1)².
  3. Simplifique o numerador: x − 1 − x − 1 = −2, logo f′(x) = −2/(x − 1)².
  4. Resposta: f′(3) = −2/4 = −0,5.

Resolvido E — Regra da cadeia

Derive f(x) = (3x² + 1)⁵.

  1. Casca: potência 5 → 5(3x² + 1)⁴.
  2. Miolo: (3x² + 1)′ = 6x.
  3. Multiplique: f′ = 5(3x² + 1)⁴ · 6x.
  4. Resposta: f′(x) = 30x·(3x² + 1)⁴.

Resolvido F — Derivadas conhecidas

Derive f(x) = 3eˣ + 2·ln(x) − cos(x).

  1. (3eˣ)′ = 3eˣ.
  2. (2·ln x)′ = 2/x.
  3. (−cos x)′ = −(−sen x) = sen x.
  4. Resposta: f′(x) = 3eˣ + 2/x + sen(x).

Questão 1 — Derivada de uma potência

Seja f(x) = a·xⁿ com a = , n = e x₀ = . Calcule f′(x₀).

Solução passo a passo

  1. Pela regra da potência: f′(x) = a·n·xⁿ⁻¹.
  2. Substitua x = x₀: f′(x₀) = a·n·x₀ⁿ⁻¹.
  3. Cuidado: o expoente da derivada é n − 1.

Questão 2 — Regra do produto

Sendo f(x) = (a·x + b)·(c·x + d), calcule f′(x₀) para a = , b = , c = , d = , x₀ = .

Solução passo a passo

  1. Chame u = a·x + b (logo u′ = a) e v = c·x + d (v′ = c).
  2. f′(x) = a·(c·x + d) + c·(a·x + b).
  3. Substitua x = x₀ na fórmula acima.

Questão 3 — Regra do quociente

Para f(x) = (a·x + b)/(c·x + d), calcule f′(x₀) com a = , b = , c = , d = , x₀ = .

Solução passo a passo

  1. u = a·x + b → u′ = a; v = c·x + d → v′ = c.
  2. f′ = (u′v − uv′)/v².
  3. f′(x) = [a·(c·x + d) − c·(a·x + b)] / (c·x + d)².
  4. Substitua x = x₀.

Questão 4 — Regra da cadeia

Solução passo a passo

  1. Casca (potência): n·(a·x + b)ⁿ⁻¹.
  2. Miolo (derivada interna): a.
  3. f′(x) = a·n·(a·x + b)ⁿ⁻¹; substitua x = x₀.
